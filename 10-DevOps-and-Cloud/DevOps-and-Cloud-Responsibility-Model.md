# DevOps and Cloud Responsibility Model

| Layer | Typical responsibility |
| --- | --- |
| Cloud provider | Facilities, physical hardware and declared managed-service components |
| Platform team | Images, node standards, automation and shared capabilities |
| System administrator | Linux host, services, storage, networking and access |
| Application team | Application code, dependencies and runtime configuration |
| Security team | Policy, risk, detection and assurance |
| SRE or operations | Reliability objectives, incidents, capacity and recovery |

For every system, replace typical assumptions with an explicit responsibility matrix covering patching, identity, network, backup, telemetry, incident response and decommissioning.

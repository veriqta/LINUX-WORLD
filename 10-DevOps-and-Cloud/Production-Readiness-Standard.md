# Production Readiness Standard

A capability is ready only when ownership, functionality, security, reliability, capacity, cost, telemetry and recovery are proven.

| Gate | Required evidence |
| --- | --- |
| Ownership | Service owner, on-call role, dependencies and support boundaries |
| Build | Reproducible source, tests, artifact identity and provenance |
| Infrastructure | Reviewed plan, state protection and drift ownership |
| Configuration | Desired state, validation and rollback |
| Security | Least privilege, secret handling, exposure and patch status |
| Reliability | SLO or success criteria, failure-mode tests and dependency handling |
| Observability | Health, metrics, logs, traces, alerts and responder action |
| Capacity and cost | Forecast, limits, reserve and budget ownership |
| Recovery | Backup, restore, rollback or roll-forward evidence |
| Release | Approval, health gates, observation window and closeout |

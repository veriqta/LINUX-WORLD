# Linux as a Platform

Linux provides the process, identity, filesystem, networking, storage, security, resource-control and service-management foundation beneath delivery and cloud platforms.

## Platform layers

| Layer | Linux concern |
| --- | --- |
| Hardware or cloud VM | boot, drivers, time and guest integration |
| Host operating system | packages, identity, systemd, filesystems and networking |
| Runtime | containers, cgroups, namespaces and security policy |
| Delivery | runners, workspaces, credentials, artifacts and deployment |
| Platform | APIs, templates, policy, telemetry and support |
| Service | ownership, reliability, capacity, recovery and incidents |

A managed service changes the responsibility boundary. It does not make responsibilities disappear.

# Learning Path

| Stage | Study | Demonstrated outcome |
| ---: | --- | --- |
| 1 | Foundations and cloud servers | Explain responsibility, state and instance lifecycle |
| 2 | CI/CD, images and registries | Trace a commit to a verified deployable artifact |
| 3 | Containers and Kubernetes nodes | Operate Linux workload runtimes and nodes |
| 4 | Configuration and infrastructure automation | Control desired state, plans, drift and recovery |
| 5 | Fleet and platform engineering | Operate reusable capabilities at scale |
| 6 | SRE and observability | Define reliability and trustworthy telemetry |
| 7 | Production integration | Prove end-to-end readiness and ownership |

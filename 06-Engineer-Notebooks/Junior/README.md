# Junior Engineer Notebook

Build disciplined habits for routine administration, verification, escalation and handover.

Prompts are detailed. Every action must be explained, verified and reversible.

## Completion standard

A notebook is complete only when the result is independently verified, evidence supports the conclusion, rollback or recovery is recorded, sensitive material is removed, and another engineer can continue the work without private context.

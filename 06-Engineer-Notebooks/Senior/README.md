# Senior Engineer Notebook

Support production architecture, reliability leadership, fleet governance and major-incident decision making.

Prompts require explicit trade-offs, failure domains, objectives, evidence quality, organizational ownership and review dates.

## Completion standard

A notebook is complete only when the result is independently verified, evidence supports the conclusion, rollback or recovery is recorded, sensitive material is removed, and another engineer can continue the work without private context.

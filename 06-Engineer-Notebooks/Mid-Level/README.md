# Mid-Level Engineer Notebook

Support independent ownership of services, cross-domain troubleshooting, controlled change and recovery.

Prompts require assumptions, competing hypotheses, operational trade-offs and measurable results.

## Completion standard

A notebook is complete only when the result is independently verified, evidence supports the conclusion, rollback or recovery is recorded, sensitive material is removed, and another engineer can continue the work without private context.

## Safe use

- Replace every placeholder before execution.
- Confirm host, identity, working directory, and target.
- Read the linked detailed section before using unfamiliar options.
- Test state-changing commands in a lab.
- Treat disk repair, formatting, recursive deletion, firewall replacement, boot repair, and identity changes as high risk.
- Sanitize command output before sharing publicly.

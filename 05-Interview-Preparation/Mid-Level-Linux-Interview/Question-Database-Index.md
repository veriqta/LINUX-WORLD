## Format in every domain

1. Concepts and mechanisms
2. Commands and options
3. Output interpretation cases
4. Troubleshooting incidents
5. Multiple choice with distractor analysis
6. True or false with corrected explanations
7. Scored practical labs

## Study rule

Attempt each item before reading the answer. For commands, reproduce the behavior in a disposable lab. For scenarios, state the evidence that would prove or reject each hypothesis. A memorized answer without verification does not count as mastery.

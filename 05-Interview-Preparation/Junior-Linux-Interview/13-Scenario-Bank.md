# Junior Scenario Bank

Use these scenarios to evaluate reasoning, not command recall. Candidates should ask clarifying questions before acting.

### 1. Linux Foundations and Help incident

**Prompt:** A recent change affects linux foundations and help. Users report an intermittent failure, but the first health check appears normal. Lead the investigation.

**Strong response:** Clarify impact and timing. Capture a baseline. Check recent change and the evidence sources in the topic guide. Build competing hypotheses. Run one low-risk test that separates them. Mitigate without destroying evidence. Verify the complete user journey, monitor recurrence, document cause and create a preventive action.

**Interviewer probes:** What is the blast radius? What evidence is volatile? What would make you roll back? How do you know recovery is complete?

**Hands-on extension:** Identify the operating system and kernel, find authoritative local help, and explain how a command is resolved.

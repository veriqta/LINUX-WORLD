# Support

Linux World is a public educational repository maintained by VERIQTA.

## Documentation questions

Before requesting help:

1. Read the relevant guide completely.
2. Review the prerequisites and safety notes.
3. Check the expected output and troubleshooting section.
4. Search existing issues and discussions.
5. Reproduce the problem in a safe test environment.

## Opening a support issue

When repository support is available through issues, include:

- The guide, lab, project, or file being used
- The exact step where the problem occurred
- Linux distribution and version
- Shell and relevant software versions
- The command that was run
- Sanitized output or logs
- Troubleshooting already attempted

Use code blocks for commands and output. Remove secrets, private keys, tokens, personal information, private addresses, internal hostnames, and confidential data.

## Support boundaries

Repository support does not include:

- Emergency production support
- Access to private systems
- Personalized system administration
- Guaranteed response times
- Recovery of lost data
- Legal, compliance, employment, or certification advice
- Troubleshooting unrelated third-party environments

## Security issues

Do not report vulnerabilities through ordinary support channels. Follow [SECURITY.md](SECURITY.md).

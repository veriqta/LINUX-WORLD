# Container Lab Files

Container definitions for labs that do not require a separate kernel, bootloader or real block device.

> Use only an isolated lab system that is owned or explicitly authorized. Never run destructive exercises on a personal workstation, shared server or production environment.

## Contribution rules

Files must identify purpose, consumers, supported platforms, version, expected result, security limits, reset behaviour and last test date. Shared files must not depend on an undocumented lab-specific state.

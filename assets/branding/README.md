# Branding

This directory contains only approved Linux World identity assets. Educational diagrams, product logos, distribution marks, and screenshots belong elsewhere.

## Required brand set

- Primary logo in editable SVG
- Light and dark background variants
- Transparent PNG exports where required
- Standalone mark
- Full wordmark
- Approved color palette
- GitHub social preview
- Repository avatar and small-size exports

Every approved asset must define minimum size, clear space, background use, prohibited modifications, owner, version, and inventory ID. Do not publish an invented or temporary logo as official branding.

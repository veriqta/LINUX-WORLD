# Banners

Banners identify repositories, sections, learning paths, project groups, and lab groups. They should be simple, readable, and consistent. A banner is not a poster and should not attempt to contain the full lesson.

## Required banner elements

- Short title
- Optional one-line purpose
- Approved Linux World branding
- Sufficient contrast
- Safe margins for responsive display
- Editable source and inventory record

Do not embed version-sensitive commands, long lists, third-party marks without review, or text that duplicates the page introduction.

# Networking And Dns

Technical diagrams for networking and dns belong here.

## Suitable content

- Application-to-wire packet path
- Routing decisions
- DNS resolution and TCP lifecycle

## Acceptance checklist

- [ ] Use lowercase kebab-case filenames.
- [ ] Record the asset in `Asset-Inventory.yml` before merge.
- [ ] Provide useful alt text or mark a purely decorative asset correctly.
- [ ] Keep editable source files when the asset was generated from source.
- [ ] Confirm ownership, license, attribution, and trademark requirements.
- [ ] Remove secrets, personal data, internal infrastructure details, and unrelated content.

## Contribution workflow

1. Start from the closest template under `assets/templates/`.
2. Create or update the editable source.
3. Export only the formats required by documentation.
4. Verify readability on desktop and mobile.
5. Complete safety, accessibility, ownership, and inventory checks.
6. Link the asset from documentation with descriptive alternative text.
7. Request technical and visual review.

# Screenshot Standards

## Before capture

Prepare a reproducible lab, set a readable terminal size and font, use a controlled prompt, close unrelated applications, disable notifications, and replace real values with reserved examples.

## Frame the evidence

Show the command or interface action, relevant output, and enough context to interpret the result. Crop unrelated content. Do not crop away evidence that changes meaning.

## Required metadata

- Asset ID and title
- Distribution and release
- Component and version
- Terminal, shell, locale, and theme when relevant
- Command or action shown
- Expected observation
- Related lesson, project, or lab
- Redaction reviewer and date
- Alt text and caption

## Editing

Allow only cropping, scaling, callouts, and irreversible redaction that do not alter technical evidence. If highlighting changes the apparent output, reject the screenshot.

## Verification

Reproduce the command, compare text in the image with the documented output, inspect the flattened export at high zoom, and obtain a second-person privacy review.

# Icon Standards

## Design system

- Use SVG as the source format.
- Define a consistent view box and safe area.
- Test at 16, 24, 32, 64, 128, and 256 pixels where relevant.
- Use simple geometry that survives small sizes.
- Supply monochrome and high-contrast behavior.
- Keep category meaning consistent across the repository.

## Accessibility

Pair icons with visible text. Do not distinguish status or difficulty only through color. Decorative icons should have empty alt text; informative icons need a text label or accessible name.

## Third-party icons

Record the icon set, creator, exact license, source URL, modifications, and required attribution. Product and distribution logos are trademarks, not general-purpose category icons.

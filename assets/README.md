# Linux World Assets

This directory is the controlled visual library for Linux World. It contains branding, banners, technical diagrams, icons, screenshots, terminal recordings, reusable templates, and attribution records.

Visuals must teach, orient, verify, or identify. Decorative material that does not improve understanding should not be committed.

## Directory responsibilities

| Directory | Purpose |
| --- | --- |
| `branding/` | Linux World identity assets |
| `banners/` | Repository and section headers |
| `diagrams/` | Technical models, flows, topologies, and decision trees |
| `icons/` | Small navigation, category, level, and status symbols |
| `screenshots/` | Reviewed visual evidence from interfaces and terminals |
| `terminal-recordings/` | Short reproducible command-line demonstrations |
| `templates/` | Approved starting files and metadata forms |
| `attribution/` | Third-party ownership, license, and permission records |

## Mandatory workflow

1. Define the question or purpose the asset serves.
2. Search the inventory to avoid duplication.
3. Choose the correct directory and template.
4. Create the editable source and required export.
5. Review technical accuracy, safety, accessibility, and licensing.
6. Add or update the inventory record.
7. Reference the asset from documentation using a relative path and meaningful alt text.
8. Recheck the asset when the related technical content changes.

## What does not belong here

- Unlicensed or unattributed third-party artwork
- Secrets, credentials, private infrastructure, or personal data
- Screenshots used instead of searchable command text
- Duplicate exports with names such as `final-new-2.png`
- Unsupported distribution instructions presented as current
- Editable files that still contain hidden sensitive layers or metadata
- Certification dumps, proprietary course captures, or copyrighted book pages

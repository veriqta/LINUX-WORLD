# Recording Standards

## Preparation

Use a disposable lab, controlled prompt, readable terminal, synthetic identity, cleared history and scrollback, and fixed dimensions. Prepare a script but type at a pace viewers can follow.

## Content

State the objective, show prerequisites, explain commands, pause at important output, verify the result, and include cleanup. Do not hide errors that affect the lesson.

## Limits

Prefer one task per recording and a short duration. Split complex lessons rather than accelerating playback until text becomes unreadable.

## Required companion files

- Original source recording
- Rendered WebM or other approved format
- Plain-text or Markdown transcript
- Command list with explanations
- Environment and version metadata
- Alt description and caption
- Safety, redaction, and licensing review

## Security

Record in a synthetic environment. Inspect every frame and the transcript for secrets, prompts, hostnames, paths, account IDs, clipboard content, and accidental notifications.

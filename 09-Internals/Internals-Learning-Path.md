# Internals Learning Path

| Stage | Subsystems | Outcome |
| ---: | --- | --- |
| 1 | Hardware, Boot, Kernel | Explain how Linux reaches userspace and represents hardware |
| 2 | Programs, Processes, System Calls | Trace a command into a scheduled process and kernel service |
| 3 | CPU, Memory, IPC, Time | Explain execution, coordination, memory and timed behavior |
| 4 | Filesystems and Storage | Follow a file operation to cache and storage media |
| 5 | Networking | Follow a packet between an application and interface |
| 6 | Namespaces and Cgroups | Explain container isolation and resource control |
| 7 | Observability and Tracing | Correlate evidence across subsystem boundaries |

Advance when the learner can explain one complete flow, observe it safely and identify what the observation cannot prove.

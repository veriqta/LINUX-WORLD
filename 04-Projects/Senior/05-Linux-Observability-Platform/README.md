# Linux Observability Platform

## Project summary

Build an observability platform for a Linux fleet that combines metrics, logs, health, inventory, service objectives, alerting, and diagnostic context.

## Level

Senior. This project requires system-wide reasoning, explicit objectives, governance, staged change, failure containment, measurable recovery, and defensible trade-offs.

## Engineering areas

- Telemetry architecture
- Cardinality
- Retention
- SLOs
- Alert design
- Capacity

## Deliverables

- Telemetry map
- Collectors
- Storage design
- Dashboards
- SLOs
- Alerts
- Retention
- Access controls
- Load and failure tests.

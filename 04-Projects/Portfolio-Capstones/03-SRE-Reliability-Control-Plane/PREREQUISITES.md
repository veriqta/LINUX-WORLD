# SRE Reliability Control Plane: Prerequisites

Complete representative Junior, Mid-Level, and Senior projects before this capstone.

## Required capabilities

- Linux administration and automation
- Network, DNS, TLS, SSH, storage, and systemd
- Security architecture and least privilege
- Metrics, logs, health, SLOs, and alerting
- Capacity, queues, limits, and backpressure
- Incident command and evidence handling
- Backup, restore, rollback, and disaster recovery
- Architecture decisions and technical communication

Use a disposable multi-host environment. Record versions, topology, capacity, costs, assumptions, and limitations.

# Linux Portfolio Capstones

These capstones combine Linux engineering, security, reliability, automation, troubleshooting, recovery, governance, and technical communication.

6. [Linux Fleet Operations System](06-Linux-Fleet-Operations-System/)

## Selection guidance

Choose one capstone after completing projects across the Junior, Mid-Level, and Senior collections. A capstone should integrate existing skills rather than introduce every concept for the first time.

## Final standard

A strong capstone is reproducible, measurable, failure-tested, recoverable, secure, documented, independently operable, honestly scoped, and safe to publish.

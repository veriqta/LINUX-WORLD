# Enterprise Linux Migration

## Capstone challenge

Plan and execute a lab migration of a legacy Linux service to a supported target distribution while preserving data, identity, network behavior, security controls, monitoring, and rollback.

## Scope

This capstone combines architecture, Linux administration, automation, security, reliability, observability, troubleshooting, recovery, governance, and technical communication.

## Core domains

- Package and library compatibility
- Service units
- Filesystem layout
- Users and IDs
- SELinux or AppArmor
- DNS
- TLS
- Backups
- And change control.

## Required deliverables

- Discovery report
- Compatibility matrix
- Target build
- Migration automation
- Data validation
- Cutover plan
- Rollback
- And post-migration review.

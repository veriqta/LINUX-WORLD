# Enterprise Linux Migration: Demonstration Guide

1. Explain the user problem in one minute.
2. Show architecture and trust boundaries.
3. Rebuild or deploy from versioned automation.
4. Complete the critical user journey.
5. Show SLO, capacity, health, logs, and change context.
6. Demonstrate a security denial.
7. Inject one controlled failure.
8. Detect, mitigate, recover, and verify.
9. Show rollback or restore.
10. Explain trade-offs, limitations, and production gaps.
11. Prove cleanup or decommissioning.

Keep the demonstration reproducible and use sanitized evidence.

# Linux Fleet Operations System: Game-Day Guide

## Scenarios

- Control-plane outage
- Partial rollout
- Compromised host
- Stale inventory
- Package regression
- Expiring credential
- And decommission failure

## Record

- Hypothesis
- Scope and abort conditions
- Healthy baseline
- Injection time
- Detection and impact
- Evidence and hypotheses
- Mitigation decision
- Recovery and user verification
- Data and security checks
- RPO, RTO, MTTD, and MTTR
- Surprises and prevention actions

Use only the disposable capstone environment.

# Linux Fleet Operations System

## Capstone challenge

Build an integrated fleet operations system for inventory, bootstrap, configuration, compliance, patching, access, telemetry, incident evidence, backup status, and lifecycle reporting.

## Scope

This capstone combines architecture, Linux administration, automation, security, reliability, observability, troubleshooting, recovery, governance, and technical communication.

## Core domains

- Identity and trust
- Signed artifacts
- Configuration convergence
- Package lifecycle
- Access review
- Resource governance
- Logging
- And audit.

## Required deliverables

- Fleet architecture
- Host enrollment
- Source of truth
- Policy
- Staged change
- Compliance
- Telemetry
- Patching
- Evidence collection
- And retirement.

# Production Linux Platform

## Capstone challenge

Design and build a small production-style Linux platform that provisions hosts, deploys a service, manages identity, stores state, exposes observability, performs backups, and survives tested failures.

## Scope

This capstone combines architecture, Linux administration, automation, security, reliability, observability, troubleshooting, recovery, governance, and technical communication.

## Core domains

- Host bootstrap
- Network boundaries
- Service management
- Reverse proxy
- Storage
- Logging
- Metrics
- Patching
- And recovery.

## Required deliverables

- A complete platform blueprint
- Automation repository
- Service deployment
- Security baseline
- Observability
- Backup and recovery
- Incident exercise
- And handoff.

# Production Linux Platform: Game-Day Guide

## Scenarios

- Host loss
- Bad deployment
- Disk exhaustion
- Certificate failure
- Dependency outage
- Credential rotation
- And full restore

## Record

- Hypothesis
- Scope and abort conditions
- Healthy baseline
- Injection time
- Detection and impact
- Evidence and hypotheses
- Mitigation decision
- Recovery and user verification
- Data and security checks
- RPO, RTO, MTTD, and MTTR
- Surprises and prevention actions

# Multi-Site Operations Simulation

## Capstone challenge

Operate a Linux service across two simulated sites with traffic routing, replicated or restorable state, site-failure procedures, observability, capacity planning, and disaster exercises.

## Scope

This capstone combines architecture, Linux administration, automation, security, reliability, observability, troubleshooting, recovery, governance, and technical communication.

## Core domains

- Failure domains
- DNS or proxy routing
- Data consistency
- Backup transfer
- Time synchronization
- Monitoring
- And operator coordination.

## Required deliverables

- Site architecture
- Traffic policy
- Data strategy
- Deployment automation
- Health model
- Failover and failback
- Game-day report
- And runbook.

# Multi-Site Operations Simulation: Game-Day Guide

## Scenarios

- Site isolation
- Asymmetric network failure
- Stale data
- DNS delay
- Capacity shortfall
- Split operation
- And failed failback

## Record

- Hypothesis
- Scope and abort conditions
- Healthy baseline
- Injection time
- Detection and impact
- Evidence and hypotheses
- Mitigation decision
- Recovery and user verification
- Data and security checks
- RPO, RTO, MTTD, and MTTR
- Surprises and prevention actions

Use only the disposable capstone environment.

# Secure Hosting Platform: Game-Day Guide

## Scenarios

- Tenant escape attempt
- Credential compromise
- Resource exhaustion
- Malicious upload
- Audit loss
- Certificate expiry
- And emergency isolation

## Record

- Hypothesis
- Scope and abort conditions
- Healthy baseline
- Injection time
- Detection and impact
- Evidence and hypotheses
- Mitigation decision
- Recovery and user verification
- Data and security checks
- RPO, RTO, MTTD, and MTTR
- Surprises and prevention actions

Use only the disposable capstone environment.

# Disk Capacity Guardian

## Project summary

Build a service that detects block and inode pressure, reports largest growth areas, and produces safe operator guidance without deleting data automatically.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- Df
- Du
- Find
- Thresholds
- Locking
- Alerts
- Trend reports

## Core deliverables

- Monitoring script
- Threshold configuration
- Scheduled unit
- Report
- Test fixture
- Alert examples
- And runbook

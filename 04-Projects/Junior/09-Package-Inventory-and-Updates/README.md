# Package Inventory and Controlled Updates

## Project summary

Create a distribution-aware workflow to inventory packages, identify updates, apply a small approved change, record results, and verify services.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- APT and DNF
- Package ownership
- Versions
- Transaction history
- Maintenance windows

## Core deliverables

- Inventory script
- Update report
- Change plan
- Backup checklist
- Verification tests
- Rollback notes
- And final report

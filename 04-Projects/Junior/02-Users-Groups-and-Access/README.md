# Users, Groups, and Access Management

## Project summary

Design and implement local user lifecycle, role groups, shared access, password policy, sudo delegation, and offboarding on a disposable Linux server.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- Identity management
- Permissions
- ACLs
- Sudoers validation
- Audit evidence

## Core deliverables

- Account matrix
- Provisioning script
- Sudo policy
- Access tests
- Offboarding procedure
- And access review report

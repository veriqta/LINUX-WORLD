# Log Analysis Toolkit

## Project summary

Build shell tools that summarize Linux and application logs by time, severity, source, status, and repeated pattern.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- Grep
- Awk
- Sed
- Sort
- Journalctl
- Input validation
- Structured reports

## Core deliverables

- Analysis scripts
- Sample sanitized logs
- Report format
- Filters
- Tests
- Usage guide
- And retention guidance

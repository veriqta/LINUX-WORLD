# Systemd-Managed Web Service

## Project summary

Deploy a simple local web application as a hardened systemd service with a dedicated account, environment file, health check, logging, and safe restart behavior.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- Systemd units
- Service users
- Sockets
- Logs
- Health checks
- Hardening directives

## Core deliverables

- Application files
- Unit file
- Environment example
- Install script
- Health check
- Rollback
- And runbook

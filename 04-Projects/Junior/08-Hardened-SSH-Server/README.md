# Hardened SSH Server

## Project summary

Configure key-based administrative SSH access with validated policy, controlled users, logging, firewall rules, and a tested recovery path.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- OpenSSH
- Keys
- Sshd validation
- Firewall
- Authentication logs
- Access recovery

## Core deliverables

- Threat model
- Sshd drop-in
- Authorized-key process
- Firewall policy
- Tests
- Backup
- And console recovery guide

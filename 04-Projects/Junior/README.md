## Recommended order

Complete the projects in sequence. Later projects assume comfort with users, permissions, services, logs, storage, networking, packages, and Bash.

## Graduation standard

A project is complete when a clean build is reproducible, every critical test passes, a failure can be diagnosed from evidence, rollback and cleanup work, and public documentation contains no sensitive data.

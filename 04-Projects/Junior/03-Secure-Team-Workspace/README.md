# Secure Team Workspace

## Project summary

Create a shared directory where a team can collaborate while preserving group ownership, controlled defaults, protected private areas, and auditable access.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- Setgid directories
- Umask
- ACLs
- Ownership
- Permission diagnosis

## Core deliverables

- Workspace hierarchy
- Group model
- ACL policy
- Onboarding script
- Access matrix
- And recovery guide

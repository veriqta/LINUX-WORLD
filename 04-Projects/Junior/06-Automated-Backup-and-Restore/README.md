# Automated Backup and Restore

## Project summary

Create versioned local backups for selected configuration and user data, with checksums, retention, scheduling, and tested restoration.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- Archives
- Rsync
- Checksums
- Cron or systemd timers
- Restore testing

## Core deliverables

- Backup script
- Configuration file
- Timer
- Retention policy
- Manifest
- Restore script
- And restore evidence

# System Baseline Audit

## Project summary

Build a repeatable audit that records hardware, operating system, services, storage, network, users, security state, and resource limits without changing the host.

## Level

Junior. This project emphasizes correct single-host administration, safe execution, verification, and clear documentation.

## Skills developed

- Inventory collection
- Safe shell scripting
- Structured output
- Evidence redaction

## Core deliverables

- A collector script
- Machine-readable report
- Human summary
- Comparison report
- And cleanup procedure

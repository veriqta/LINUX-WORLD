# Evidence

Store sanitized project proof here. Use stable names such as `FUN-01.txt`, `SEC-01.txt`, and `REC-01.txt` that match the acceptance tests and evidence register.

Never store secrets, private keys, tokens, personal data, real public addresses, unrestricted logs, or private infrastructure details. The `private/` subdirectory is ignored as a safeguard, but sensitive evidence should normally remain outside the repository.

# Controlled Patch Management

## Project summary

Build a repeatable patch workflow for a small Linux fleet with inventory, risk classification, canary deployment, verification, rollback, and reporting.

## Level

Mid-Level. This project requires integration across several Linux layers, competing design options, automation, failure testing, and operational ownership.

## Skills

- Package management
- Maintenance windows
- Canaries
- Service verification
- Reboot coordination

## Deliverables

- Fleet inventory
- Patch policy
- Canary plan
- Automation
- Prechecks
- Postchecks
- Rollback paths
- And compliance report.

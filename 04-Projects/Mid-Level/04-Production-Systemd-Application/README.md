# Production systemd Application

## Project summary

Package and operate a multi-process application with dedicated identities, dependencies, socket or timer units, resource limits, hardening, logs, and upgrades.

## Level

Mid-Level. This project requires integration across several Linux layers, competing design options, automation, failure testing, and operational ownership.

## Skills

- Advanced systemd
- Dependencies
- Cgroups
- Drop-ins
- Lifecycle management

## Deliverables

- Unit set
- Installation automation
- Environment model
- Health checks
- Resource policy
- Upgrade and rollback procedures.

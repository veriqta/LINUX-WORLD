# Configuration Drift Detector

## Project summary

Create a system that records approved file state and detects unauthorized or accidental changes across several Linux hosts.

## Level

Mid-Level. This project requires integration across several Linux layers, competing design options, automation, failure testing, and operational ownership.

## Skills

- Checksums
- Metadata
- Baselines
- Remote collection
- Scheduling
- Signed reports

## Deliverables

- Baseline manifest
- Collector
- Comparison engine
- Exclusions
- Alert output
- Tests
- And investigation runbook

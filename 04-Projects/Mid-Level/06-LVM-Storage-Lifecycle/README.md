# LVM Storage Lifecycle

## Project summary

Design, provision, grow, monitor, snapshot, back up, restore, and retire application storage using LVM and a supported filesystem.

## Level

Mid-Level. This project requires integration across several Linux layers, competing design options, automation, failure testing, and operational ownership.

## Skills

- Block devices
- LVM
- Filesystems
- Mounts
- Snapshots
- Backups

## Deliverables

- Storage map
- Provisioning automation
- Fstab policy
- Growth procedure
- Monitoring
- Backup and restore evidence
- Decommission plan.

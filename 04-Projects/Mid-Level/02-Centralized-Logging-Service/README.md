# Centralized Logging Service

## Project summary

Collect Linux and application logs from multiple lab hosts into a central service with parsing, retention, search, access control, and delivery monitoring.

## Level

Mid-Level. This project requires integration across several Linux layers, competing design options, automation, failure testing, and operational ownership.

## Skills

- Remote logging
- Structured events
- TLS transport
- Queues
- Retention
- Search

## Deliverables

- Collector and client configuration
- Schema
- Transport security
- Dashboards or queries
- Retention policy
- Backlog test
- And recovery guide

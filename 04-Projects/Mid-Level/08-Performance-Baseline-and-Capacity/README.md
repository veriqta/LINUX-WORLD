# Performance Baseline and Capacity Study

## Project summary

Measure a Linux service under controlled load, establish normal ranges, identify saturation, and produce a capacity and alerting recommendation.

## Level

Mid-Level. This project requires integration across several Linux layers, competing design options, automation, failure testing, and operational ownership.

## Skills

- Load generation
- USE method
- Latency percentiles
- CPU
- Memory
- I/O
- Network

## Deliverables

- Test plan
- Workload definition
- Baseline data
- Graphs
- Bottleneck analysis
- Capacity model
- Alerts
- And limitations.

# Security Learning Path

| Stage | Study | Demonstrated outcome |
| ---: | --- | --- |
| 1 | Foundations | Model assets, threats, trust and risk |
| 2 | Hardening and access | Reduce attack surface and manage least privilege |
| 3 | SSH, firewalls and services | Protect administrative and network exposure |
| 4 | SELinux or AppArmor | Diagnose and enforce mandatory access control |
| 5 | Auditing and detection | Produce and interpret security evidence |
| 6 | Secrets, integrity and vulnerabilities | Protect trust material and software lifecycle |
| 7 | Kernel, containers and automation | Control runtime and fleet-scale risk |
| 8 | Backup, incident response and forensics | Preserve evidence, contain and recover |

Study the mandatory access-control system used by the target distribution first, then learn the other model for cross-platform competence. Advance only after completing a safe implementation, negative test, rollback and explanation at each stage.

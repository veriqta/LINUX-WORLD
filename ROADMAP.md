# Linux World Roadmap

Linux World is being developed as a practical Linux knowledge base spanning foundational learning, administration, troubleshooting, projects, interviews, security, internals, DevOps, cloud, and production operations.

The roadmap communicates direction. It does not guarantee release dates or a fixed publication order.

## Phase 1: Foundation

- Establish repository policies and standards
- Publish the complete beginner-to-advanced learning path
- Build the command index and essential cheat sheets
- Publish safe lab setup guidance
- Establish contribution, conduct, support, and security processes

## Phase 2: Practical administration

- Users, groups, permissions, and privileged access
- Processes, jobs, signals, and system resources
- Package management
- systemd and service operations
- Storage, filesystems, mounts, LVM, and backups
- Networking, DNS, SSH, and firewalls
- Bash scripting and automation

## Phase 3: Troubleshooting and projects

- Junior troubleshooting collection
- Mid-level troubleshooting collection
- Senior troubleshooting collection
- Failure-injection labs
- Production case files
- Junior, mid-level, and senior projects
- Portfolio capstones

## Phase 4: Professional readiness

- Junior Linux interview preparation
- Mid-level Linux interview preparation
- Senior Linux interview preparation
- Practical assessments
- Mock interviews
- Junior Linux Notebook
- Senior Linux Notebook

## Phase 5: Advanced engineering

- Linux security and hardening
- Linux internals
- Performance engineering
- Containers, namespaces, and cgroups
- Linux for CI/CD and cloud platforms
- Kubernetes node operations
- SRE and observability

## Phase 6: Production operations

- Operational readiness
- Runbooks and playbooks
- On-call practices
- Monitoring and alerting
- Capacity planning
- Patch and change management
- Backup, restore, and disaster recovery
- Incident response and postmortems

## Continuous work

- Correct technical errors
- Update commands and version-specific behavior
- Validate distribution differences
- Repair broken links
- Improve accessibility
- Expand tested examples
- Review security guidance
- Improve navigation and searchability

## Suggesting roadmap items

Open a focused issue describing the audience, problem, expected value, proposed scope, and supporting sources. Roadmap inclusion does not guarantee acceptance or a delivery date.

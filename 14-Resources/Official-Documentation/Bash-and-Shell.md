# Bash and Shell Documentation

## Primary sources

| Source | Use |
| --- | --- |
| [GNU Bash manual](https://www.gnu.org/software/bash/manual/) | Authoritative Bash language reference |
| [Bash project](https://www.gnu.org/software/bash/) | Releases and project information |
| [POSIX shell command language](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html) | Portable shell requirements |

## Recommended method

Use the Bash manual for Bash features and POSIX for portable shell behavior. Confirm the interpreter named in the script shebang.

## Verification checklist

- Confirm the running version and distribution.
- Prefer a local manual when it matches the installed package.
- Record defaults, prerequisites, warnings, and privilege requirements.
- Validate configuration syntax before reload or restart.
- Capture before and after state.
- Test rollback in a safe environment.
- Review release notes and known issues for version changes.

## Citation record

Record page title, organization, canonical URL, product version, section, and access date.

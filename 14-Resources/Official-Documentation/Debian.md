# Debian Documentation

## Primary sources

| Source | Use |
| --- | --- |
| [Debian documentation](https://www.debian.org/doc/) | Official manuals and guides |
| [Debian Administrator's Handbook](https://www.debian.org/doc/manuals/debian-handbook/) | Administration reference |
| [Debian security](https://www.debian.org/security/) | Security advisories |
| [Debian releases](https://www.debian.org/releases/) | Release notes and lifecycle |

## Recommended method

Distinguish Stable, Testing, Unstable, backports, and the release named by the running system.

## Verification checklist

- Confirm the running version and distribution.
- Prefer a local manual when it matches the installed package.
- Record defaults, prerequisites, warnings, and privilege requirements.
- Validate configuration syntax before reload or restart.
- Capture before and after state.
- Test rollback in a safe environment.
- Review release notes and known issues for version changes.

## Citation record

Record page title, organization, canonical URL, product version, section, and access date.

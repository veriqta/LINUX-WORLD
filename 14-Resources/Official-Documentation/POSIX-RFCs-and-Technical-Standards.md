# POSIX, RFCs, and Technical Standards

## Primary standards

- [The Open Group Base Specifications](https://pubs.opengroup.org/onlinepubs/9799919799/), POSIX interfaces and utilities
- [RFC Editor](https://www.rfc-editor.org/), published internet standards and related documents
- [IANA protocol registries](https://www.iana.org/protocols), assigned protocol values
- [Filesystem Hierarchy Standard](https://refspecs.linuxfoundation.org/fhs.shtml), filesystem layout guidance
- [Open Container Initiative](https://opencontainers.org/), container image, runtime, and distribution specifications

## How to use standards

Read status, updates, errata, normative language, and implementation scope. A standard describes a contract. A Linux implementation may add extensions or preserve older behavior.

## Practical sequence

1. Identify the protocol or interface.
2. Read an accessible overview.
3. Locate the current standard and updates.
4. Compare the Linux manual or project documentation.
5. Observe real behavior with a packet capture, trace, or safe test.

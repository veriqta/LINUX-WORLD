# Non-English Channels

Technical quality must be reviewed in the teaching language. Machine translation or automatic captions alone are not enough for security-sensitive endorsement.

## Required language review

Confirm terminology, command accuracy, spoken warnings, subtitle accuracy, cultural clarity, version scope, accessibility, and the instructor's distinction between translated product names and literal commands.

Until a fluent technical reviewer completes the record, list a candidate as `review-required`, not recommended.

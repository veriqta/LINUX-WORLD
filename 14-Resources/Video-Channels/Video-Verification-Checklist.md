# Video Verification Checklist

## Identity and scope

- [ ] Owner and canonical channel confirmed
- [ ] Publication date checked
- [ ] Distribution and software versions identified
- [ ] Prerequisites and privileges understood
- [ ] Sponsorship or commercial relationship identified

## Technical review

- [ ] Commands and options checked in manuals
- [ ] Configuration paths verified for the stated release
- [ ] Security controls remain enabled unless the lesson justifies a safe exception
- [ ] Expected output compared with a lab result
- [ ] Persistent changes identified
- [ ] Rollback and cleanup tested
- [ ] Official documentation supports key claims

## Learning review

- [ ] Terminal text is readable
- [ ] Captions or transcript assessed
- [ ] Instructor explains decisions, not only keystrokes
- [ ] Learner can reproduce the task independently
- [ ] At least one failure and verification method is understood

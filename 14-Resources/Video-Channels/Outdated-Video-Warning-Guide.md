# Outdated Video Warning Guide

## Warning levels

- **Current:** Tested against a supported release.
- **Version-specific:** Accurate for the named version; compare with the running system.
- **Conceptual:** Concepts remain useful, but commands or interfaces may have changed.
- **Archived:** Do not follow operational steps without a current replacement.
- **Unsafe:** Retained only as a documented warning or removed.

## Common signs of age

Unsupported distributions, SysV-only service instructions, `ifconfig` presented as the only network tool, deprecated package repositories, obsolete TLS settings, old Kubernetes APIs, old Docker networking behavior, and advice to disable security controls.

## Required note

State the original version, affected commands, current replacement, verification source, and review date.

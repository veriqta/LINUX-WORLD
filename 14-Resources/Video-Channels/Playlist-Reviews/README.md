# Playlist Reviews

A channel review does not replace a playlist review. Use the following record for every recommended sequence.

## Required record

- Playlist title and canonical URL
- Channel owner and classification
- Publication and update range
- Distribution and software versions
- Learning objectives and prerequisites
- Lesson sequence and estimated study time
- Commands and configuration paths sampled
- Safety, rollback, and cleanup review
- Missing subjects and known errors
- Captions, transcript, screen readability, and language
- Official documentation used for verification
- Lab and assessment evidence
- Reviewer, review date, next review, and decision

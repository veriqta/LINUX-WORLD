# Video Channels

This section curates channels and playlists that help learners observe Linux administration, troubleshooting, security, internals, and production operations.

Linux World recommends specific educational value, not every statement made by a creator. A strong channel may still contain outdated, sponsored, distribution-specific, or incomplete videos.

## Start safely

1. Read [How to Learn from Video](How-to-Learn-from-Video.md).
2. Select a [learning path](Learning-Paths/Beginner-Foundations.md).
3. Check the channel classification and review date.
4. Confirm the distribution and software version.
5. Reproduce the lesson in an isolated lab.
6. Verify important behavior in official documentation.
7. Complete a practical task without replaying the video.

## Classifications

- **Official:** Project, distribution, vendor, or standards organization.
- **Reviewed instructor:** Independent teacher whose relevant material has been assessed.
- **Supplemental:** Useful for selected subjects, not a complete primary path.
- **Archived:** Historically valuable or inactive material with explicit warnings.

Subscriber count is not a technical quality measure.

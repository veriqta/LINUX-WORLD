# Recommended Starting Playlists

Playlist titles and URLs change more often than channel identities. Use the canonical channel search links below, confirm the playlist date and version, then complete the verification checklist.

| Goal | Starting source | Search focus | Pair with |
| --- | --- | --- | --- |
| Command-line foundations | [Learn Linux TV](https://www.youtube.com/@LearnLinuxTV) | Linux essentials or command line | GNU manuals and Linux World foundations |
| System administration | [Learn Linux TV](https://www.youtube.com/@LearnLinuxTV) | system administration | Distribution documentation and labs |
| Enterprise Linux | [Red Hat Enterprise Linux](https://www.youtube.com/@RedHatEnterpriseLinux) | current RHEL administration | Current RHEL docs |
| RHCSA preparation | [Sander van Vugt](https://www.youtube.com/@sandervanvugt) | current RHCSA version | Current Red Hat exam objectives |
| Shell scripting | [The Urban Penguin](https://www.youtube.com/@theurbanpenguin) | Bash scripting | Bash manual and ShellCheck |
| Kubernetes | [CNCF](https://www.youtube.com/@cncf) | Kubernetes concepts and maintainer talks | Version-matched Kubernetes docs |
| Ansible | [Jeff Geerling](https://www.youtube.com/@JeffGeerling) | Ansible | Ansible docs and a disposable inventory |
| Systems performance | [Linux Foundation](https://www.youtube.com/@linuxfoundation) | performance, tracing, eBPF | Kernel docs and Brendan Gregg methodology |

Linux World avoids permanent deep links until a playlist has a completed review record. This prevents renamed, replaced, or outdated playlists from appearing current.

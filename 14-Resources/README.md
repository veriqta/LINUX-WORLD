# Linux World Resources

This section is the research library for Linux World. It connects learners and working system administrators to authoritative documentation, carefully selected websites, books, terminology, and reviewed video material.

Resources complement the teaching, labs, projects, and operational material in Linux World. They do not replace hands-on practice or independent verification.

## Resource workflow

1. Learn the concept in Linux World.
2. Confirm version-sensitive behavior in official documentation.
3. Use a selected book, website, or video for another explanation.
4. reproduce commands in an isolated lab.
5. Record commands, outputs, errors, and conclusions.
6. Verify the result with an independent command or test.

## Trust labels

| Label | Meaning |
| --- | --- |
| Primary | Official project, vendor, standards body, or installed manual |
| Maintainer | Material from people who build or maintain the technology |
| Reviewed educator | Independent teaching material reviewed against primary sources |
| Supplemental | Useful for a limited purpose, with stated limitations |
| Archived | Retained for historical or conceptual value, not current procedures |

## Important boundaries

Linux World does not publish or link to pirated books, leaked examinations, certification dumps, unlicensed courses, undisclosed affiliate links, or resources that encourage unsafe production changes. Inclusion is not a permanent endorsement. Every resource remains subject to review, correction, replacement, or archival.

## Reporting a problem

Report broken links, outdated versions, inaccessible material, unsafe procedures, undisclosed commercial relationships, or technical errors through the repository issue process. Include the resource name, URL, affected statement, evidence, and a suggested correction when possible.

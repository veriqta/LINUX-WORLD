# How to Use the Resources

This guide explains how to select, verify, study, and cite material from the Linux World resource library.

## Choose the right source

| Question | Best starting source |
| --- | --- |
| What does this term mean? | Glossary |
| What behavior is supported? | Official documentation or local manual |
| How can the subject be studied in depth? | A current book |
| Where can a task be seen in action? | A reviewed video or playlist |
| Where can another explanation or lab be found? | A reviewed website |
| What is required for an examination? | The certification owner's current objectives |

## The four-pass study method

1. **Orient.** Identify the objective, prerequisites, distribution, software version, and expected result.
2. **Learn.** Read or watch actively. Stop to define unfamiliar terms and predict command results.
3. **Practise.** Reproduce the task in an isolated virtual machine or container. Do not paste unknown commands into production.
4. **Verify.** Compare the result with official documentation, inspect system state, test a failure, and explain the result in your own words.

## Before running a command

- Identify whether it changes data, identity, permissions, storage, networking, boot, firewall, or security policy.
- Read the command manual and inspect every option.
- Replace example hostnames, devices, users, and paths deliberately.
- Confirm the target environment and current working directory.
- Capture the before state and prepare rollback.
- Use a lab for destructive, privileged, or unfamiliar operations.

## Version-sensitive material

Check the publication date, distribution release, package version, init system, firewall implementation, security module, and configuration path. A concept may remain correct while its commands are no longer appropriate.

## Evidence of learning

A completed resource should produce evidence such as notes, a working configuration, command output, test results, a failure and recovery record, or a small project. Watching, bookmarking, or copying does not demonstrate competence.

## Citation

Credit the author or organization, title, canonical URL, version or edition, access date, and the specific section used. Do not copy substantial copyrighted material into Linux World.

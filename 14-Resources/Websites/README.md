# Reviewed Websites

This directory contains supplementary learning, research, laboratory, community, and operational websites. Official project and vendor sources belong in `Official-Documentation`.

Every website must state what it is useful for, its authority, version risks, access requirements, and last review date. Community answers are hypotheses until reproduced and verified.

## Safe use

Never paste an unfamiliar command directly into a privileged shell. Inspect downloads, preserve access, create rollback, and test on disposable infrastructure.

# Free and Legally Available Books

| Book or collection | Legal source | Focus | Notes |
| --- | --- | --- | --- |
| The Linux Command Line | [Author website](https://linuxcommand.org/tlcl.php) | Command line and shell | Author-provided edition |
| Debian Administrator's Handbook | [Debian](https://www.debian.org/doc/manuals/debian-handbook/) | Debian administration | Officially available online |
| Linux From Scratch | [LFS](https://www.linuxfromscratch.org/lfs/) | Building a Linux system | Versioned project book |
| Beyond Linux From Scratch | [BLFS](https://www.linuxfromscratch.org/blfs/) | Extending an LFS system | Versioned project book |
| Site Reliability Engineering | [Google SRE](https://sre.google/books/) | Reliability engineering | Publisher-authorized online edition |
| The Site Reliability Workbook | [Google SRE](https://sre.google/books/) | Applied SRE | Publisher-authorized online edition |
| GNU manuals | [GNU](https://www.gnu.org/manual/manual.html) | Tools and languages | Official project manuals |

Free access does not remove copyright. Follow the license and attribution requirements of each work.

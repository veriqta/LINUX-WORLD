# Acronyms and Abbreviations

| Acronym | Expansion | Operational context |
| --- | --- | --- |
| ABI | Application Binary Interface | Binary compatibility |
| ACL | Access Control List | Fine-grained filesystem permissions |
| API | Application Programming Interface | Software interaction contract |
| ARP | Address Resolution Protocol | IPv4 neighbor discovery |
| BPF/eBPF | Berkeley Packet Filter/extended BPF | Tracing, networking, security |
| CIDR | Classless Inter-Domain Routing | Address prefixes and routes |
| CPU | Central Processing Unit | Execution capacity |
| DAC | Discretionary Access Control | Owner-controlled permissions |
| DNS | Domain Name System | Name resolution |
| ELF | Executable and Linkable Format | Linux executables and libraries |
| FHS | Filesystem Hierarchy Standard | Directory purposes |
| FQDN | Fully Qualified Domain Name | Complete DNS name |
| GID | Group Identifier | Kernel group identity |
| I/O | Input/Output | Device and data transfer |
| IPC | Interprocess Communication | Process coordination |
| IRQ | Interrupt Request | Hardware event delivery |
| LSM | Linux Security Module | Kernel security framework |
| LVM | Logical Volume Manager | Storage abstraction |
| MAC | Mandatory Access Control | SELinux or AppArmor policy |
| MTU | Maximum Transmission Unit | Largest packet size at a link |
| NAT | Network Address Translation | Address or port rewriting |
| NIC | Network Interface Controller | Network device |
| NTP | Network Time Protocol | Time synchronization |
| NUMA | Non-Uniform Memory Access | CPU and memory locality |
| OOM | Out Of Memory | Severe allocation failure |
| PAM | Pluggable Authentication Modules | Authentication policy stack |
| PID | Process Identifier | Process identity |
| PKI | Public Key Infrastructure | Certificate trust and lifecycle |
| POSIX | Portable Operating System Interface | Standardized Unix interfaces |
| RAID | Redundant Array of Independent Disks | Multi-device storage layout |
| RPO | Recovery Point Objective | Maximum acceptable data loss window |
| RTO | Recovery Time Objective | Target service restoration time |
| SLI | Service Level Indicator | Measured reliability signal |
| SLO | Service Level Objective | Reliability target |
| SSH | Secure Shell | Encrypted remote administration |
| TLS | Transport Layer Security | Encrypted authenticated transport |
| TTY | Teletype terminal interface | Interactive terminal behavior |
| UID | User Identifier | Kernel user identity |
| VFS | Virtual Filesystem | Kernel filesystem abstraction |
| VM | Virtual Machine | Virtualized computer environment |

# Linux World Glossary

The glossary provides concise definitions, operational meaning, inspection methods, common confusions, and related concepts. It is a reference, not a replacement for the learning path.

## Ways to browse

- [A to Z index](A-to-Z-Index.md)
- [Acronyms and abbreviations](Acronyms-and-Abbreviations.md)
- [Commonly confused terms](Commonly-Confused-Terms.md)
- [Topic indexes](Topic-Indexes/Administration-Terms.md)

## Entry pattern

Each entry explains what the term means, why a system administrator should care, how it can be observed safely, and what is often misunderstood. Commands are illustrative and must be checked on the learner's distribution.

## Scope

The glossary covers command-line work, administration, boot, systemd, storage, filesystems, networking, identity, security, processes, memory, the kernel, containers, cloud operations, reliability, and incident response.

# Start Here

Welcome to Linux World.

This section helps new readers prepare a safe Linux practice environment, understand the recommended study order, and begin the complete 20-part Beginner-to-Advanced course with confidence.

No previous Linux experience is required.

## Begin in this order

1. Read [Prerequisites](Prerequisites.md).
2. Set up a practice system with [Lab Environment Setup](Lab-Environment-Setup.md).
3. Read [Lab Safety](Lab-Safety.md) before running commands.
4. Read [How to Use Linux World](How-to-Use-Linux-World.md).
5. Select the appropriate route in [Choose Your Learning Path](Choose-Your-Learning-Path.md).
6. Copy or download the [Progress Tracker](Progress-Tracker.md).
7. Begin [Part 1: Linux Foundations and Getting Started](../01-Beginner-to-Advanced/01-Linux-Foundations-and-Getting-Started.md).

## What Linux World teaches

The Beginner-to-Advanced course develops practical ability across:

- Linux foundations and terminal use
- Filesystem navigation and file management
- Users, groups, root, and `sudo`
- Permissions, ownership, and access control
- Text viewing, editing, and searching
- Pipes, redirection, and command chaining
- Processes and job management
- Services, systemd, and boot
- Package management
- Environment variables and shell configuration
- Networking, DNS, SSH, and remote administration
- Disks, partitions, filesystems, and mounts
- CPU, memory, swap, and performance
- Logs, monitoring, and troubleshooting
- Bash scripting and automation
- Cron, archives, and backups
- Security and beginner server hardening
- A complete administration and troubleshooting project

## Recommended learning method

For every part:

1. Read the learning objectives.
2. Study the explanations before copying commands.
3. Type commands manually in a safe lab.
4. Compare the result with the expected output.
5. Complete each exercise and knowledge check.
6. Practise the troubleshooting examples.
7. Record mistakes, discoveries, and useful commands.
8. Mark the part complete in the Progress Tracker.

Linux is learned through deliberate practice. Reading alone is not enough.

## Important safety warning

Linux commands can delete data, change permissions, stop services, break networking, or make a system unbootable. Use a disposable virtual machine or another authorized test environment. Never practise destructive operations on a production server or a computer containing important data.

Read [Lab Safety](Lab-Safety.md) before beginning.

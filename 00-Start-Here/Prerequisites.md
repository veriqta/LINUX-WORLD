# Prerequisites

Linux World begins from first principles. Previous Linux experience is not required.

## Required mindset

Readers should be willing to:

- Type commands instead of only copying them
- Read error messages
- Practise regularly
- Work carefully with paths and privileges
- Keep notes
- Verify changes
- Repeat exercises
- Troubleshoot mistakes instead of hiding them

## Required equipment

At minimum:

- A computer capable of running a Linux environment
- Reliable access to the learning files
- Sufficient storage for a virtual machine or another lab option
- An internet connection for installation, updates, and documentation
- A plain-text editor for notes

## Recommended computer resources

For a local virtual machine:

- A modern 64-bit processor
- Hardware virtualization enabled when required
- At least 8 GB host RAM, with approximately 4 GB available to the lab when possible
- At least 25 GB free disk space for the lab

These are recommendations, not universal requirements. Lighter configurations can support many foundational exercises.

## Required Linux environment

Use one of the following:

- Ubuntu Server LTS virtual machine, recommended
- Authorized cloud virtual machine
- Windows Subsystem for Linux for compatible lessons
- Spare computer dedicated to learning
- Disposable container for short compatible exercises

Read [Lab Environment Setup](Lab-Environment-Setup.md) before choosing.

## Knowledge prerequisites

No technical background is required, but the following basic abilities help:

- Opening an application
- Creating and organizing local files
- Downloading a file from an official website
- Copying and pasting text carefully
- Following written instructions in order
- Recognizing that usernames, paths, and addresses must be adapted to the local environment

## Accounts and access

The lab should include:

- A regular user account
- Permission to use `sudo` for authorized administrative tasks
- Access to the virtual-machine console or another recovery method

Do not use an employer, school, or client system unless explicit permission has been granted.

## Helpful but optional tools

- A second terminal window
- Git for downloading and tracking repository content
- A Markdown viewer or editor
- A password manager
- A diagram or note-taking tool
- A second virtual machine for networking and SSH practice

## Time commitment

The Beginner-to-Advanced course is comprehensive. Progress depends on experience, practice time, and how deeply labs are repeated.

A useful study session includes:

- 20 to 40 minutes of focused reading
- 30 to 90 minutes of hands-on practice
- Time to troubleshoot and record results

There is no requirement to finish one part in a single session.

Confirm that:

- [ ] A safe Linux lab is available.

- [ ] A regular user can sign in.
- [ ] Administrative access works when required.
